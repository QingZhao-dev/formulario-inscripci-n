
# Formulario de inscripción

## Descripción
Formulario web que permite introducir los datos necesarios para una inscripción. Incluye validación de campos y una confirmación final con la información introducida.

## Funcionalidades
- Introducir los datos de una inscripción.
- Validar los campos del formulario.
- Gestionar campos dinámicos.
- Mostrar una confirmación con la información introducida.

## Tecnologías utilizadas
- **HTML5:** estructura del formulario y campos de entrada.
- **CSS3:** diseño y organización de los elementos.
- **JavaScript:** validación de datos, gestión de campos dinámicos y confirmación final.
